# github-achievements-sandbox
Personal sandbox project for learning Git/GitHub workflows (branches, PRs, issues, discussions).

## Usage

This repo includes a tiny CLI notes tool (`notes.py`) with three commands:

```bash
# Add a note
python notes.py add "Buy milk"

# List all notes
python notes.py list

# Remove a note by its number in the list
python notes.py remove 1
```

Notes are stored as plain text lines in a local `notes.txt` file, which is
created automatically the first time you add a note.

## Purpose

This repository is used as a personal sandbox for practicing real Git and
GitHub workflows: feature branches, pull requests, issues, and discussions.
